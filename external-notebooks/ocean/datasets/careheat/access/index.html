The careheat datababase has several datasets related to marine heatwaves (MHWs) and cold spells (MCSs).

  1. careheat_mhw_2d.zarr - Events are identified for each pixel following the methodology of Hobday et al. (2016) with different preprocessing steps.

  2. ssa_careheat_mhw_2d.zarr - Events are identified for each pixel following the methodology of Hobday et al. (2016) with different preprocessing steps.

  3. careheat_mhw_metrics_2d.zarr - intensity, duration, heterogeneity and rate metrics for careheat_mhw_2d events.

  4. ssa_careheat_mhw_metrics_2d.zarr - intensity, duration, heterogeneity and rate metrics for ssa_careheat_mhw_2d events.

  5. careheat4d-med.zarr - 4d careheat events for the Mediterranian.

  • EO4SOCIETY Website: https://eo4society.esa.int/projects/careheat/

  • Original Data Source: https://zenodo.org/records/8154587 - not processed https://data-cersat.ifremer.fr/data/marine-heat-wave/esa-careheat/cnr/v2/ https://sextant.ifremer.fr/record/87a33c31-5930-4379-8cfa-0b29ceee9756/

  • Reference: https://opensciencedata.esa.int/projects/careheat/collection

Metrics dataset¶

The “date_start” and “date_end” are another key part of the data.

For example, one can compute the duration of a events at certain location by doing:

import pandas as pd

ds = xr.open_zarr(items["careheat-database-careheat_mhw_metrics_2d"].assets["data"].href)

dstart = ds["date_start"].sel(lon=slice(-6.062, 36.06), lat=slice(30.27, 45.98), drop=True)
dend = ds["date_end"].sel(lon=slice(-6.062, 36.06), lat=slice(30.27, 45.98), drop=True)

keep = (dstart.values >= 20200501) & (dend.values < 20200700)

def parse_ymd(block):
    a = block.ravel()
    dates = pd.to_datetime(
        {
            "year": a // 10000,
            "month": (a // 100) % 100,
            "day": a % 100,
        },
        errors="coerce",
    )
    return dates.to_numpy(dtype="datetime64[ns]").reshape(block.shape)

def convert_dates(da):
    return xr.apply_ufunc(
        parse_ymd,
        da.where(keep),
        dask="parallelized",
        output_dtypes=[np.dtype("datetime64[ns]")],
    )

start = convert_dates(dstart)
end = convert_dates(dend)

duration_days = ((end - start) / np.timedelta64(1, "D")).rename(
    "duration_days"
)
duration_days.attrs = {"units": "days"}
